Revise LaTeX papers in VS Code using local Codex or Claude Code sessions, with PDF annotations and live TeXpresso previews.

- Select text or a region, attach a revision request, and send it to the current agent session.
- Review source diffs and matching PDF highlights; accept individual changes and browse local approval history.
- Preview citations, figures, and tables on hover at the current paper scale and display pixel density.
- Configure named Claude profiles, including a separate `claude_config_dir`.
- Copy Libertine ligatures such as `tt`, `ff`, and `ffi` as readable text, with uniform selection highlighting and individual letter selection.

### Installation

This VSIX targets **macOS Apple Silicon (ARM64)**. Download `pdf-local-copilot-0.7.3.vsix` below, then run **Extensions: Install from VSIX…** in VS Code. Reload the VS Code window after updating.

Install the [Homebrew libraries and TeX prerequisites](https://github.com/wyxu95/pdf-local-copilot#prerequisites), and authenticate your local Codex or Claude Code CLI. The native binaries link against Homebrew libraries.

The interaction design is inspired by [Papilot](https://github.com/PapilotAI/papilot); live rendering uses [TeXpresso](https://github.com/let-def/texpresso) and its headless fork. See the repository's third-party notices for licenses.
