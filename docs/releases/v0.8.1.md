Use Windows VS Code with a WSL2 backend or connect through Remote SSH to a Mac or Linux workspace.

- Adds Linux x64 and ARM64 packages for Ubuntu 24.04, including WSL2.
- Keeps the source, TeXpresso, and local Codex/Claude sessions on the workspace host while showing the PDF and chat in Windows VS Code.
- Enables source-to-PDF menus in remote windows.
- Adds **PDF Local Copilot: Check Setup** to report the actual backend host and detected tools.
- Automatically accepts reviewed edits included in Git commits, including partial staging, while retaining uncommitted changes and clearing the matching PDF markers.
- Restores active review state from the project when another VS Code workspace host opens it.
- Coordinates simultaneous cold starts and atomically publishes the shared TeX format cache.
- Packages each target separately and publishes the release after all target builds succeed.

Download the VSIX matching the **workspace host**:

| Host | Asset suffix |
| --- | --- |
| Apple Silicon Mac | `darwin-arm64.vsix` |
| WSL2 / Ubuntu 24.04 x86_64 | `linux-x64.vsix` |
| WSL2 / Ubuntu 24.04 aarch64 | `linux-arm64.vsix` |

Connect the VS Code window to WSL or SSH first, then use **Extensions: Install from VSIX…**. Tools and agent login/configuration live on that host.

See the [Windows and remote installation guide](https://github.com/wyxu95/pdf-local-copilot/blob/main/docs/windows-remote.md) for dependencies and setup. macOS packages retain their Homebrew prerequisites; Linux packages use Ubuntu 24.04 runtime libraries.
