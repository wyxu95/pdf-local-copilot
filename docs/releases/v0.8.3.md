Mac builds use the shared Homebrew SDL2 library path, supporting both classic SDL2 and sdl2-compat installations.

Page previews reuse identical images across TeXpresso updates while delivering current text coordinates, reference links, and source revisions.

- Sends unchanged page images once per reader and reuses them on subsequent updates.
- Delivers complete current metadata for selection, annotations, links, and SyncTeX.
- Restores full images when a reader reloads or its page cache needs an image again.
- Keeps independent PDF readers and preview sessions isolated.
- Adds `npm run install:mac -- /path/to/package.vsix` to install and verify one build in both Mac desktop VS Code and its Remote SSH server.
- Shows the installed version in **PDF Local Copilot: Check Setup**.

Download the VSIX matching the workspace host: `darwin-arm64` for an Apple Silicon Mac, or `linux-x64` / `linux-arm64` for Ubuntu 24.04 and WSL2. See the [installation guide](https://github.com/wyxu95/pdf-local-copilot/blob/main/docs/windows-remote.md).
